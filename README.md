# Desarrollo_Soft
El proyecto Tech-Jimmy System es un sistema integral de gestión enfocado en estandarizar, automatizar y digitalizar las operaciones de un taller de reparación técnica y tienda minorista de tecnología. Su propósito principal es administrar eficientemente la recepción, diagnóstico y entrega de dispositivos móviles y laptops, garantizando el seguimiento de fallas y estados dinámicos del servicio.
Además, integra módulos para el control de inventario multicategoría (refacciones de taller y accesorios comercializables), gestión de puntos de venta (POS) y un submódulo para el registro contable de recargas telefónicas.
#Lenguaje
Para su construcción se empleará el lenguaje Java con el framework Spring Boot, junto con el entorno de desarrollo integrado Eclipse IDE (Spring Tool Suite), cuya elección es completamente libre dentro del proyecto. La justificación técnica radica en que Spring Boot ofrece una infraestructura robusta, altamente escalable y desacoplada mediante arquitecturas Spring MVC y APIs RESTful, facilitando la inyección de dependencias, la seguridad empresarial y la gestión transaccional segura (ACID). Por su parte, Eclipse IDE brinda un ecosistema de desarrollo consolidado, integración nativa con herramientas Maven/Gradle, soporte avanzado de depuración y compatibilidad total con el stack empresarial de Java.
